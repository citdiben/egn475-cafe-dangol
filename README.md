# Café Calle Ocho

## Project Overview

This is a simple Flask web application created for EGN 475: Software Prototyping at Atlantis University.

## Application Routes

- `/` — Displays the café welcome message.
- `/about` — Displays a short description of the café.

## Technologies Used

- Python 3.12
- Flask
- Visual Studio Code
- Git and GitHub

## How to Run

1. Activate the Python virtual environment.
2. Install Flask if it is not already installed.
3. Run the application using:

   `python -m flask --app app run --debug`

4. Open `http://127.0.0.1:5000/` in a browser.

## Project Purpose

This project demonstrates basic Flask routing, browser testing, version control, and AI-assisted software prototyping.
